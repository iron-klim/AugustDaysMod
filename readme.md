# Мод Августовские дни на игру Кризис в Кремле 2
## Добавляет в игру сценарий на путч ГКЧП в 1991 году: события, политиков, страны и другое. https://steamcommunity.com/sharedfiles/filedetails/?id=3606829008
## Обзор проекта:
* assets - статичные ресурсы. Состояние игры на 16.08.1991 (state.json: страны, технологии, произошедшие события, принятые решения, модификаторы, войны), поправки к сценарию игры (scenario.json), справочник поддерживаемых стран: собственные показатели, руководство, названия (countries.json), тексты сюжетных событий, решений и концовок (story.json), флаги (images) и силуэты политиков без портретов (portraits), локализации. Правила игры мод не подменяет.
* src - основной код мода
    * Assets - управление загрузкой ресурсов
    * Catalog - справочник стран: старт за страну, руководство, меню новой игры, флаги и названия
    * Compat - отключение и пересчет союзных механик, когда игрок управляет не СССР
    * DevTools - инструменты разработки, включаются файлами в папке данных игры
    * Endings - концовки мода
    * Events - игровые события
    * Scenarios - настройка сценария
    * Storage - система хранения мода: данные мода в файле сохранения
    * Story - сюжетные события, решения и концовки на данных из story.json
    * Union - СССР как отдельная страна под управлением ИИ, когда игрок управляет другой страной
* scripts - полезные скрипты: deploy-dev.sh собирает мод и выкладывает его в папку Workshop, game.ps1 перезапускает игру с гарантией одного экземпляра
